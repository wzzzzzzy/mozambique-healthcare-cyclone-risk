# Figures and tables

Where each manuscript figure and table comes from. Script file names keep the
numbering of an earlier draft (for example, `figure_02_electricity_sources`
is manuscript Figure 3); the table maps them.

Variables used below:

- `R`: main-case results folder (`$LINE_HAZARD_ROOT`, pipeline stages 2–5).
- `F`: output folder of `run_figures_t24.sbatch`.
- `FS`: output folder of `run_figures_t24_solar_exposure.sbatch`.
- `B`: boundary data (`data/README.md`).

Run the commands from the repository root with `PYTHONPATH` set (see the
README). Every script refuses to overwrite existing outputs.
